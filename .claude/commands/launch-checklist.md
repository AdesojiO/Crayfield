# Crayfield Launch Checklist Review

Review and track the launch readiness of the Crayfield website against the minimum viable launch requirements from the project brief.

If $ARGUMENTS contains a file path or URL, read/fetch it first and cross-reference against the checklist below. Otherwise, prompt the user for the current status of each item.

---

## Minimum Viable Launch Checklist

### Domain & Identity
- [ ] Domain registered (e.g. crayfield.co.uk)
- [ ] Business email set up (e.g. hello@crayfield.co.uk)
- [ ] Company number visible in footer
- [ ] WhatsApp Business account configured with quick replies

### Product Pages (min 5–10)
- [ ] Product name + variant selector (weights)
- [ ] Clear product photos (front label, back label, loose product, pack-shot on white)
- [ ] Allergen statement (shellfish) on every applicable page
- [ ] Storage guidance present
- [ ] Delivery estimate shown
- [ ] Batch/best-before format defined
- [ ] Reviews widget installed (even empty at launch)

### Wholesale Page
- [ ] Wholesale landing page live
- [ ] Enquiry form working (sends to email/CRM)
- [ ] Price list available (PDF download or gated)
- [ ] WhatsApp button on page (sticky on mobile)
- [ ] MOQ and lead times stated clearly

### Policy Pages
- [ ] Delivery & Returns
- [ ] Privacy Policy (GDPR-compliant, mentions data processor if using Shopify/Stripe)
- [ ] Terms & Conditions
- [ ] Cookie Policy + consent banner

### Technical
- [ ] SSL certificate active (https://)
- [ ] Google Analytics 4 installed
- [ ] Meta Pixel installed (if running ads at launch)
- [ ] XML sitemap submitted to Google Search Console
- [ ] robots.txt configured correctly
- [ ] Page speed tested (target LCP <2.5s on mobile)
- [ ] All payment methods tested end-to-end (Shopify Payments / Stripe + PayPal)

### Local & Brand Presence
- [ ] Google Business Profile created (if applicable)
- [ ] Instagram/Facebook page linked from site

---

## Output Format

For each section, report:
- **Done** — item complete
- **In progress** — partially done, note what's missing
- **Not started** — needs action

End with a prioritised list of blockers that must be resolved before going live.
