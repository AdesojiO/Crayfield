# Crayfield SEO Audit

Run an SEO audit on the page or content provided in **$ARGUMENTS**.

If a URL or file path is given, read/fetch the content first. If raw HTML or copy is pasted, analyse that directly.

---

## Audit Checklist

### 1. Title Tag
- [ ] Present and ≤60 characters?
- [ ] Contains primary keyword?
- [ ] Includes brand name (Crayfield)?
- Verdict + suggested rewrite if needed

### 2. Meta Description
- [ ] Present and ≤155 characters?
- [ ] Includes a call-to-action?
- [ ] Mentions key benefit or product?
- Verdict + suggested rewrite if needed

### 3. URL Slug
- [ ] Lowercase, hyphenated?
- [ ] Contains target keyword?
- [ ] Short and descriptive?
- Verdict + suggestion

### 4. H1 Heading
- [ ] One H1 present?
- [ ] Matches or closely reflects the title tag intent?
- Verdict + suggestion

### 5. Heading Hierarchy (H2–H4)
- List headings found
- [ ] Logical hierarchy?
- [ ] Keywords naturally present?
- Suggestions

### 6. Primary Keyword Usage
- Identify the implied primary keyword
- Check density (aim 1–2%, not stuffed)
- Flag if missing from key locations (title, H1, first 100 words, image alt text)

### 7. Image Alt Text
- [ ] All images have alt text?
- [ ] Alt text is descriptive and keyword-relevant?
- List missing or weak alt texts

### 8. Internal Linking
- [ ] Links to related products, categories, or wholesale page?
- Suggestions for internal link opportunities

### 9. Schema / Structured Data (if applicable)
- [ ] Product schema present (for product pages)?
- [ ] Review schema present?
- Suggestions

### 10. Core Web Vitals & Performance Notes
- Note any obvious performance issues (large images, render-blocking scripts)
- Recommend image format (WebP) and lazy loading if applicable

### 11. Mobile Readability
- [ ] CTAs large enough for thumb tap?
- [ ] No horizontal scroll?
- [ ] Sticky add-to-cart / WhatsApp button present?

---

## Priority Action List
Summarise the top 3–5 fixes ranked by impact, with specific rewrites where relevant.

## Quick Wins
List any fixes that take <15 minutes and have high impact (e.g. missing alt text, title tag tweak).
